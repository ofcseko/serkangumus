# Serkan Gümüş — Portfolio

Hand-coded static site (HTML, CSS, vanilla JS). No build step, no frameworks.

- `index.html` — all content, English + Turkish (`data-l="en"` / `data-l="tr"`)
- `css/style.css` — styles
- `js/main.js` — language switch, menu, reveal, lightbox, contact form
- `js/sculpture.js` — the CODE → FORM 3D ribbon (plain canvas, no WebGL)
- `assets/` — fonts, images, CV, share image

Deploy: push to GitHub, import the repo in Vercel (Framework preset: Other). 

Contact form uses FormSubmit (formsubmit.co). The first message sends an activation email to srkangmss@gmail.com — click "Activate" once.
